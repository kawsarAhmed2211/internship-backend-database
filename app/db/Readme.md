# Homie.ai — Data & Commerce Backend

## Overview

This repository contains the initial backend foundation for Homie.ai's Data & Commerce system. It provides a FastAPI application, a PostgreSQL database connection through Supabase, SQLAlchemy models for furniture products and retailer offers, and Alembic database migrations.

Homie.ai distinguishes between a **Product**, which represents a furniture item or variant in the shared catalogue, and an **Offer**, which represents a specific retailer's listing for that product.

## Current Features

- **FastAPI:** API application with a homepage and database health-check endpoint.
- **PostgreSQL / Supabase:** Hosted database connection configured through environment variables.
- **SQLAlchemy:** ORM models for `Product` and `Offer`.
- **Alembic:** Version-controlled database schema migrations.
- **Product catalogue:** Product details, dimensions, colours, materials, style tags, ratings and review-analysis fields.
- **Retailer offers:** Store listings, prices, stock status, return policies, price history and affiliate-link metadata.

## Getting Started

### Prerequisites

- Python 3.12 or compatible version
- A Supabase PostgreSQL project
- Git

### 1. Clone the repository

```bash
git clone <repository-url>
cd Internship
```

Replace `<repository-url>` with your team's actual Git repository URL.

### 2. Create and activate a virtual environment

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root:

```dotenv
DATABASE_URL=postgresql+psycopg://USERNAME:PASSWORD@HOST:PORT/DATABASE
```

Replace the placeholders with your own Supabase connection details. Use the connection method configured for your environment.

**Security:** Never commit `.env`, database passwords, API keys or other secrets to Git.

### 5. Apply database migrations

```powershell
alembic upgrade head
```

This applies the migrations included in the repository. Make sure `DATABASE_URL` points to the intended database before running this command.

### 6. Start the API

```powershell
uvicorn app.main:app --reload
```

The development server should be available at `http://127.0.0.1:8000`.

## Database Models

### Product

Represents a furniture item or variant in the shared catalogue.

Includes fields for brand, name, category, dimensions, colour, material, images, style tags, review statistics, review summaries and data provenance.

### Offer

Represents a specific retailer's listing for a product.

Includes the product reference, retailer name, listing URL, price, stock status, return information, live-check metadata, price history and affiliate-link metadata.

A product can have multiple offers from different retailers.

## Database Migrations

Database schema changes are managed with Alembic.

Generate a migration after updating the SQLAlchemy models:

```powershell
alembic revision --autogenerate -m "describe your change"
```

Review the generated migration before applying it:

```powershell
alembic upgrade head
```

Check the current database revision:

```powershell
alembic current
```

Autogenerated migrations must be reviewed before use, especially when working with a shared or production database.
